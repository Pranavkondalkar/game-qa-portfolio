# Pranav Kondalkar — Game QA Portfolio

A responsive, static portfolio ready for GitHub Pages.

## Local preview

Open `index.html` directly, or run:

```bash
cd portfolio
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## GitHub Pages deployment

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the repository branch and `/ (root)` if `index.html` is at the repository root.
5. To keep the site under the `/portfolio` folder, set the Pages source to the branch and `/portfolio` folder if GitHub supports that folder configuration.

Because this project uses relative asset paths, it also works at `https://<username>.github.io/<repository>/portfolio/`.

## Editable links

LinkedIn is configured in `index.html`. Replace or improve the downloadable resume at `assets/Pranav_Kondalkar_Resume.html`.
